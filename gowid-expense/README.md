# gowid-expense

Gowid 법인카드 경비를 Claude Code / Codex에서 자연어로 조회·제출하는 스킬.

> "내 미제출 경비 보여줘" → 조회 → "1번 식비로 제출해" → 완료

## 설치

```bash
# Claude Code (원본: eoash/ash-skills)
npx skills add eoash/ash-skills --skill gowid-expense -g -a claude-code

# Codex를 쓰는 경우에만 ~/.codex/skills/gowid-expense 에 연결되도록 배치
```

API 키는 내장되어 있지 않습니다. 환경변수 `GOWID_API_KEY`가 필요합니다(운영팀에 현행 키 요청). 권장: `~/.gowid-api-key`(chmod 600)에 저장하고 `.zshrc`에서 `export GOWID_API_KEY="$(cat ~/.gowid-api-key)"`.

## 사용법

Claude Code 또는 Codex에서 자연어로 요청하면 됩니다.

**경비 조회**
```
"내 경비 보여줘"
"미제출 경비"
"이번 달 경비 내역"
```

**경비 제출 (일반)**
```
"1번 IT서비스로 제출해"                    → 자동 분류 규칙에 매칭되는 항목
"32625805 도서구입비로 제출해"              → expense ID 직접 지정
"Notion 결제 건 IT서비스로 제출해"          → 가맹점명으로 찾기
```

**식비 제출 (참석자 필요)**
```
"3번 점심식비로 제출해, 김찬희랑 먹었어"    → 참석자 자동 매칭
"야근식비로 제출해"                        → 점심/야근은 사용자가 지정 (시각 기준 미확정)
"금요미식회로 제출 — 팀 전체"              → 인당 15,000원 한도
```

**제출한 건 수정**
```
"37774914 서류발급비로 바꿔"                → update (승인 전 SUBMITTED만)
"비비큐 건 접대비, 외부 참석자 이한빈"       → --external 로 외부 참석자 입력
```

**규칙 검색**
```
"자동규칙 검색 Notion"                     → Notion 관련 분류 규칙 확인
"zoom 규칙"                               → Zoom 관련 규칙
```

**기타**
```
"용도 목록"                               → 58개 전체 카테고리
"팀원 목록"                               → 식비 참석자 선택용
"경비 상세 32625805"                      → 특정 건 상세 정보
```

## 작동 방식

1. `GOWID_EMAIL` 또는 `git config user.email`로 본인 식별 (재직 상태·이메일 1명 일치만 인정)
2. 해당 월 지출내역을 끝까지 읽고, 경비 상세의 소유자 userId가 본인인 미제출 건만 표시
3. 341개 자동 분류 규칙으로 용도 추천 (긴 패턴 우선, 자리표시 답은 자동 기입하지 않음)
4. Claude가 대화형으로 제출 처리 (메모, 참석자 등)
5. 제출 후 재조회로 상태·용도·필수항목·참석자·메모를 검사. 이미 제출된 건은 건너뜀. 승인 전 변경은 `update`(생략한 필드는 기존 값 유지)

가승인·원천 취소/환불 건은 제출하지 않습니다. 원화 한도 검증에는 실제 원화 금액만 사용하며, 외화 금액을 원화로 대입하지 않습니다.

### 보안 한계

API 키는 회사 공용이다. 위 본인 검사는 이 헬퍼 안에서의 실수 방지일 뿐 인증이 아니다. 키를 가진 사람은 다른 사람 이메일을 설정하거나 API를 직접 호출해 다른 사람 경비를 다룰 수 있다. 진짜 본인 제한에는 서버측 인증 중계(Slack/SSO 신원 → 중계가 소유자 검사 후 Gowid 호출)나 사용자별 자격증명이 필요하다.

## 지원 기능

- **경비 조회**: 본인 카드의 미제출 내역 (전체 사용자 조회 `--all`은 제거됨)
- **경비 제출**: 용도 지정 + 필수항목/메모 + 내부·외부 참석자
- **제출 건 수정**: 승인 전(SUBMITTED) 용도·필수항목·참석자 변경 (`update`)
- **상세 조회**: 카드번호, 승인일, 금액, 현재 상태
- **용도 목록**: 58개 활성 카테고리
- **팀원 목록**: 참석자 선택용
- **자동규칙**: 가맹점별 자동 분류 규칙 검색 (341개)
- **규칙 제안**: GitHub Issue로 새 규칙 제안

## 자주 쓰는 용도

**식비**

| 용도 | 한도 | 필요 정보 |
|------|------|-----------|
| 점심식비 | 인당 12,000원 | 초과 시 참석자 필수 |
| 야근식비 | 인당 12,000원 | 초과 시 참석자 필수 (점심/야근 시각 기준은 확인 중) |
| 금요미식회 | 인당 15,000원 | 금요일 점심, 참석자 필수 |
| 회식비 | 없음 | 참석자 필수 |

**SaaS / 구독**

| 용도 | 예시 | 필요 정보 |
|------|------|-----------|
| IT서비스 이용료 | Notion, Slack, Zoom, GitHub, Figma, AWS | `서비스,프로그램명 기입`에 서비스명 |
| 멤버십 구독료 | WeWork, 공유오피스, ChatGPT | 필수항목에 서비스명/구독명 |
| 매거진 구독료 | 뉴닉, Economist, 뉴스레터 | 필수항목에 매체명/구독명 |

**교통 / 출장**

| 용도 | 필요 정보 |
|------|-----------|
| 업무교통비 | 출발지/도착지 (택시, 버스, 지하철) |
| 야근교통비 | 22시 이후 귀가 택시 |
| 주차비 | - |

**기타**

| 용도 | 필요 정보 |
|------|-----------|
| 도서구입비 | - |
| 소모품비(10만원이하) | 사무용품, 어댑터 등 |
| 우편비 | 택배, 등기 |
| 업무추진비 | 촬영 스탭식비/음료 등, 프로젝트 지정 필수 |

## API 제출 제한

필수항목이 있는 용도도 `--requirements '{"항목id": ["답변"]}'`로 API 제출할 수 있습니다(V2, 답변은 배열). 항목 id는 `purposes`로 확인합니다.

| 용도 | 필수항목 |
|------|---------|
| 업무교통비 / 야근교통비 | 출발지·도착지 / 출퇴근 시간 |
| 도서구입비 | 책 제목 |
| 서류발급비 / 주차비 | 프로젝트명 |
| 접대비 | 상대방 소속/이름 (+ `--external` 외부 참석자) |

제한: 제출 취소 API는 없고, 승인(APPROVED) 이후 변경은 Gowid 웹에서 합니다.

## 요구사항

- [Claude Code](https://claude.ai/claude-code) 설치
- Python 3.9+
- Gowid 법인카드 계정 (git email과 Gowid 이메일 일치 필요)
- git email이 다른 경우: Claude Code settings에 `"env": { "GOWID_EMAIL": "본인@eoeoeo.net" }` 추가
