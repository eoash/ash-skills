# 렌더 설정

영상 하나당 JSON 파일 하나를 작업 폴더에 둔다. 모든 시간은 **원본 영상의 초**다.

```json
{
  "headline": ["K 뷰티, 미국 진출하려면", "실력부터 기르세요"],
  "pieces": [[818.84, 822.14], [825.88, 829.99]],
  "pics": [
    {"until": [0, 820.79], "shot": [818.72, 820.79], "x": 1370},
    {"until": [1, 826.30], "shot": [822.99, 824.59], "x": 840, "start": 823.05},
    {"until": null, "shot": [824.59, 832.50], "x": 1370}
  ],
  "caps": [
    {"p": 0, "s": 818.84, "e": 819.96, "t": "저한테 항상 하는 얘기가"},
    {"p": 1, "s": 825.88, "e": 827.72, "t": "근데 저는 절대 그렇게\n하지 말라고 그러거든요"}
  ]
}
```

## 항목

| 항목 | 뜻 |
|---|---|
| `headline` | 제목. 한두 줄이고, 길면 글자 크기가 자동으로 줄어든다 |
| `pieces` | 들려줄 음성 조각 `[시작, 끝]`을 재생 순서대로 나열한다 |
| `pics` | 화면 목록. 재생 순서대로 나열한다 |
| `pics[].until` | 이 그림이 끝나는 지점 `[조각 번호, 원본 시간]`. 마지막 그림만 `null` |
| `pics[].shot` | 이 그림이 속한 원본 샷의 `[시작, 끝]`. `shots.py` 출력에서 가져온다. 경계 밖 프레임은 쓰지 않는다 |
| `pics[].x` | 가운데 둘 인물의 원본 x 좌표(0~1920). 자료 화면이면 `"band"` |
| `pics[].start` | 음성과 다른 시점을 보여줄 때 그 원본 시간. 생략하면 음성에 맞춘다 |
| `pics[].h` | 원본에서 잘라 쓸 높이. 기본 900. 노란 소제목이 보이면 860 |
| `caps` | 자막. `p`는 조각 번호, `s`와 `e`는 원본 시간, `t`는 내용(`\n`으로 줄바꿈) |
| `caps[].who` | `main`(기본, 흰색) 또는 `host`(네온 노랑) |
| `band_crop` | 선택. 자료 화면 영역 `[w, h, x, y]`. 기본 `[1344, 653, 288, 162]` |
| `logo_box` | 선택. 지울 원본 로고 영역 `[x, y, w, h]`. 기본 `[1660, 30, 240, 120]`. 로고가 없으면 `null` |

## 그림 정하기

`shots.py <원본> <a> <b> <시트.jpg>`는 샷 목록과 시트를 만든다. 쓸 구간보다 몇 초 넓게 잡는다. 샷은 요청한 범위에서 잘리므로 끝 샷의 경계는 믿지 않는다. 구간이 길면 칸이 많아져 보기 어려우니 영상 전체는 `overview.py`로 본다. 경계 표시는 `ANGLE`(앵글 변경)과 `JUMP?`(작은 화면 변화)가 있다. `JUMP?`는 같은 앵글 안의 점프 컷일 수도, 큰 손동작일 수도 있어서 시트에서 확인한다. 시트의 각 칸은 원본을 4분의 1로 줄인 것이고, 노란 세로줄은 원본 192픽셀 간격이다. 칸에서 인물 얼굴 중심이 몇 번째 줄 근처인지 보고 `x`를 정한다.

기본 크롭은 원본 1080x900을 그대로 쓴다. 클로즈업에서 얼굴이 너무 크게 나오지 않도록 확대하지 않는다. 아래 두 경우에는 값을 바꾼다.

- 옆 사람의 옷이나 손이 조금 걸리면 먼저 `x`를 옮긴다. 그래도 걸리면 `h`를 줄여 더 좁게 담는다(예: `"h": 860`). `h`가 작을수록 확대된다.
- 자료 화면은 원본 영상 안에 작은 화면으로 들어가 있다. `"x": "band"`로 그 영역만 잘라 위아래를 검게 채운다.

현재 EO 인터뷰 형식은 다음과 같다. 다른 형식이면 시트를 보고 맞춘다.

- 1920x1080이고, 원본 자막 띠는 y≈890 아래에 있다.
- 노란 소제목은 y≈870~945에 나온다. 이 구간은 `h`를 860으로 줄인다.
- EO 로고는 오른쪽 위 x1660~1900, y30~150에 있다. 렌더할 때 지운다.
- 자료 화면은 x288~1632, y162~918에 있고, 그 안의 자막은 y≈834에 있다. 그래서 기본 영역의 높이가 653이다.

## 컷 지점 정하기

`asr.py words`는 단어별 시간과 조용한 구간을 보여준다.

- 조각의 시작과 끝은 조용한 구간 안에 둔다. 단어 시간만 믿으면 말끝이 잘릴 수 있다. 조용한 구간 목록에는 단어 속 틈도 섞여 있으니 단어 시간과 함께 보고 단어 사이의 틈을 고른다.
- Whisper는 짧은 조각에서 자주 틀린다. 앞뒤 문맥이 있는 긴 구간의 결과를 우선한다.
- 말 중간의 단어 하나를 뺄 때는 그 단어 앞뒤 틈을 찾고, 틈이 없으면 빼면 부자연스러울 수 있다고 알린다.

## 자막 시간 정하기

- 자막의 `s`와 `e`는 조각 안에 있어야 한다. 조각이 바뀌는 곳에서는 자막을 나눈다.
- 같은 내용이 이음매를 사이에 두고 이어지면 같은 `t`로 두 번 쓴다. 렌더할 때 하나로 합쳐진다.
- 0.6초보다 짧은 틈은 앞 자막을 늘려 메우고, 컷 근처(약 0.13초 안)에서 시작하는 자막은 컷에 맞춘다. 렌더러가 자동으로 처리한다.
- 줄이 너무 길면 `--check`에서 오류가 난다.

## 검사 메시지

| 메시지 | 대응 |
|---|---|
| `over the 30s target` | 사용자의 대본이면 그대로 두고 길이를 알린다 |
| `over the 40s limit` | 줄일 곳을 사용자에게 묻는다 |
| `holds a frozen frame` | 샷이 짧아 화면이 멈춘다. 더 긴 샷으로 바꾼다 |
| `runs in sync across an audio splice` | 이음매 뒤로 입 모양이 어긋난다. 그림을 이음매에서 나누거나, 듣는 사람이나 와이드 샷을 `start`와 함께 쓴다 |
| `jump cut` | 같은 샷의 다른 시점이 바로 이어진다. 사이에 다른 샷을 넣는다 |

`qa.py`의 메시지는 다음과 같다.

| 메시지 | 대응 |
|---|---|
| `picture changes inside a shot` | 시트에서 그 프레임을 본다. 원본의 점프 컷이면 [편집 규칙](edit-rules.md)대로 가리거나 알린다. 손동작이면 그대로 둔다 |
| `blip` | 샷 경계가 틀린 경우가 많다. `shots.py`로 경계를 다시 보고 그림 목록을 고친다 |
| `planned cuts with a small picture change` | 같은 앵글끼리 이어진 컷일 수 있다. 시트에서 보고 같은 방법으로 처리한다 |
